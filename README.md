## 🚀 Featured Projects

### 🧠 **Multi-Agent Health Coach**
A medical assistant built with **LangGraph, Qdrant, and Neo4j**, using evidence-based content from MedlinePlus.  
It analyzes symptoms, retrieves verified medical content, and gives structured guidance using vector search + knowledge graph RAG.

### 🎓 **Parwaaz – AI Learning Assistant**
An interactive middle-school learning tool that generates **quizzes, summaries, flashcards, and explanations** using OpenAI.  
Built with Flask, TailwindCSS, and modular AI components.

### 📊 **RAG Evaluation Framework**
A lightweight evaluation pipeline comparing AI-generated responses against reference answers using a structured scoring rubric (Relevance, Accuracy, Fluency).
